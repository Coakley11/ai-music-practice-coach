# P1 Continue, Practice Log and insight identity

Saved workflow identity stays separate from current Music setup.

Manual logs begin without an inferred resource, instrument or key. Quick Save captures the explicitly selected resource. Renaming a linked entry detaches its association. Activity uses the saved entry, stays non-blocking, and creates no Music Continue task for a log milestone.

Recording facts capture recording ID and upload-owned source/title/instrument. Reviews correlate by recording ID. Insights and Directory event details cannot borrow a later log or global instrument.

Global Music Continue uses exact event envelopes for typed Practice, Backing, and Catalog Mission/Coaching. Missions remain started. Logs, Composition save milestones, passive changes, uploads without durable take restoration, and unsupported P2 workflows do not qualify. Labels, grouping and URLs share one envelope. Recency chooses the workflow; priority only breaks ties. Historical Activity Resume and generic Directory Open stay separate.

Practice Analysis owns history rows, aggregate metadata and its run ID. It excludes unrelated active-song context. Its explicit save crosses the post-restore cooldown while startup/hydration/library guards remain intact. Its Applied Intelligence URL carries the analysis run ID and stays external.

Validation and browser evidence are in the workspace-level .p1-identity report. This candidate includes no push, merge or deployment.
