# Portfolio Screenshot Guide — AI Music Practice Coach

## Enable Screenshot Mode

1. Sidebar → **Portfolio Screenshot Mode**
2. Sidebar Pages → **Song Practice** (practice page)
3. Select an active song with chord chart loaded

---

## Hero Page: Active Song Practice

**Why:** Unique portfolio differentiator — adaptive practice studio with real song context.

### Desktop

| Step | Action |
|------|--------|
| 1 | Pick a catalog song on Song Selection |
| 2 | Open **Song Practice** page |
| 3 | Select a section (Verse or Chorus) |
| 4 | Enable Screenshot Mode |
| 5 | Capture hero banner + chord chart + section focus panel |

**Filename:** `01-active-song-practice.png`

### Mobile

- Hero banner + chord strip + section selector
- **Filename:** `02-active-song-practice-mobile.png`

### What makes it impressive

- Song-specific practice (not generic metronome app)
- Section-aware chord charts and practice cues
- Instrument/key context visible
- Combines music pedagogy + interactive UX
