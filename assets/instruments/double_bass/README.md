# Double bass

Pizzicato notes from the 1958 Otto Rubner double bass, played and mapped by D. Smolken (`sfzinstruments/dsmolken.double-bass`).
Released under CC0: see `LICENSE`. Royalty-free for commercial and non-commercial use.

Trimmed, converted to mono 16-bit FLAC and measured for pitch. The loudest peak of each pluck is gently eased; nothing else is processed.
