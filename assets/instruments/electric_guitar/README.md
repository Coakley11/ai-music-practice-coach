# Electric guitar

Notes and dead strokes from an Epiphone Emily the Strange guitar, played and mapped by D. Smolken (`sfzinstruments/karoryfer.emilyguitar`), recorded direct.
Released under CC0: see `LICENSE`. Royalty-free for commercial and non-commercial use.

Trimmed, converted to mono 16-bit FLAC and measured for pitch. The amp and cabinet are applied at render time.
