# Recorded drum kit

Mono, trimmed hits from **Virtuosity Drums**, a contemporary jazz kit recorded at Virtuosity Musical
Instruments in Boston and played by Austin McMahon. Released under CC0 1.0 (see `LICENSE`).

Source: https://github.com/sfzinstruments/virtuosity_drums

Overhead microphones for cymbals, mid microphones for the kit, close microphones for the kick and snare
used in Rock and Funk.
