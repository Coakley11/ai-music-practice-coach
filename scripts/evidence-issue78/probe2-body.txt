Accepted: WAV, MP3, M4A, MP4, MOV, OGG, FLAC. Maximum file size: 500 MB.

How this works: Align = shift a layer earlier/later · Mute = silence a layer · Solo = hear one layer by itself · Monitor backing = hear the backing while recording · Loop section = repeat the selected section while recording
